무엇을 할 수 있나요

실제 데이터 모델링에 필요한 표기법과 산출물을 갖추고 있습니다.

🔗

외래키 자동 생성

엔티티 사이를 연결하면 부모의 기본키를 따라 자식 쪽에 외래키 컬럼이 자동으로 만들어집니다. 관계를 지우거나 종류를 바꾸면 컬럼 정리도 함께 이뤄집니다.

📐

바커 표기법

식별·비식별·선택 관계를 점선과 실선, 까마귀발 기호로 구분해 표현합니다. 1:1과 1:M을 지원하며, 관계선의 좌우 절반을 각각 다르게 설정할 수도 있습니다.

🧩

배타적 서브타입

슈퍼타입 안에 서브타입 박스를 중첩해 그리는 바커식 SubSet 표기를 지원합니다. 특정 서브타입에만 걸리는 관계도 지정할 수 있습니다.

🗄️

MySQL DDL 내보내기

완성한 다이어그램을 MySQL 8 기준 CREATE TABLE 스크립트로 내려받습니다. 기본키·외래키 제약과 논리명 주석까지 함께 생성됩니다.

🏷️

물리명과 논리명 병기

영문 물리명과 한글 논리명을 함께 적어 두면 다이어그램과 DDL 주석 양쪽에 표시됩니다. 국내 실무에서 쓰는 산출물 형식에 맞습니다.

🔍

편한 편집

더블클릭으로 이름과 타입을 바로 고치고, 여러 엔티티를 한 번에 골라 옮깁니다. 자동 정렬, 되돌리기·다시 실행, 메모 붙이기를 지원합니다.

👥

링크로 공유

공유 링크를 만들면 다른 사람이 같은 다이어그램을 실시간으로 함께 볼 수 있습니다. 링크는 언제든 폐기할 수 있습니다.

💾

저장과 내보내기

로그인하면 5초마다 자동 저장되고 여러 다이어그램을 목록으로 관리합니다. JSON 파일이나 PNG 이미지로 내려받을 수도 있습니다.

세 단계면 충분합니다

처음 열고 나서 DDL을 손에 쥐기까지의 흐름입니다.

  1. 엔티티를 추가합니다

    왼쪽 사이드바의 Add Entity를 누르면 캔버스에 테이블이 하나 생깁니다. 이름과 컬럼은 노드 위에서 더블클릭해 바로 고칠 수 있습니다.

  2. 관계를 연결합니다

    엔티티 테두리의 연결점을 끌어다 다른 엔티티에 놓고 관계 종류를 고르면 됩니다. 외래키 컬럼은 이때 자동으로 만들어집니다.

  3. DDL로 내보냅니다

    오른쪽 아래 도구막대의 SQL 버튼을 누르면 MySQL DDL 파일이 내려받아집니다. 그림이 필요하면 PNG로도 저장할 수 있습니다.

자주 묻는 질문

회원가입을 해야 쓸 수 있나요?

아닙니다. 로그인하지 않아도 다이어그램을 그리고 SQL이나 PNG로 내보낼 수 있습니다. 다만 작업물을 서버에 보관하거나 여러 다이어그램을 목록으로 관리하려면 로그인이 필요합니다. 로그인하지 않은 상태에서는 JSON 파일로 내려받아 보관하세요.

어떤 데이터베이스의 DDL을 내보낼 수 있나요?

현재는 MySQL 8 기준 DDL을 지원합니다. UUID는 CHAR(36)으로, VARCHAR·CHAR·DECIMAL 등은 지정한 크기를 반영해 변환하며, 기본키·외래키·NOT NULL·UNIQUE 제약과 논리명 주석이 함께 생성됩니다. 부모 테이블이 먼저 오도록 정렬하고 순환 참조에 대비해 외래키 검사를 잠시 끄는 구문으로 감쌉니다.

관계를 연결하면 외래키가 어떻게 만들어지나요?

부모 엔티티의 기본키를 따라 자식 쪽에 컬럼이 생깁니다. 관계 종류에 따라 플래그가 달라집니다. 식별 관계면 자식의 기본키에 포함되면서 NOT NULL이 되고, 비식별 관계면 기본키에서 빠진 채 NOT NULL이 되며, 선택 관계면 NULL을 허용합니다. 관계를 지우거나 부모 엔티티를 삭제하면 따라 만들어졌던 컬럼도 함께 정리됩니다.

만든 다이어그램을 다른 사람과 같이 볼 수 있나요?

공유 링크를 발급하면 링크를 받은 사람이 같은 다이어그램을 실시간으로 볼 수 있습니다. 현재 편집은 소유자만 가능하고 링크로 들어온 사람은 읽기 전용입니다. 링크는 언제든 폐기할 수 있으며, 폐기하면 그 링크로는 더 이상 접근할 수 없습니다.

비용이 드나요?

무료로 제공합니다. 서비스 운영 비용의 일부는 페이지에 게재되는 광고로 충당합니다.

영어로도 쓸 수 있나요?

네. 편집기 상단 바의 🌐 버튼으로 한국어와 영어를 전환할 수 있고, 사용 설명서와 가이드 문서도 영문판이 준비되어 있습니다.
