MCP 연결 가이드 Claude Code

Claude Code에서 자연어로 이 EasyERD 서비스의 다이어그램을 만들고 편집하도록 MCP 서버를 연결하는 방법입니다.

개요

MCP(Model Context Protocol)는 Claude Code 같은 AI 클라이언트가 외부 도구를 호출하도록 연결하는 표준입니다. EasyERD에는 전용 MCP 서버가 포함돼 있어, 연결하면 다음처럼 말할 수 있습니다:

"user 엔티티 만들고 PK는 seq(사용자고유번호) integer, name(이름) varchar(100)으로 추가해줘" → 엔티티·컬럼·관계가 자동으로 생성되고 서버에 저장됩니다.

동작 구조는 다음과 같습니다. MCP 서버는 변경할 때마다 다이어그램을 통째로 받아 → 변형 → 다시 저장합니다.

Claude Code ──stdio──▶ erd-mcp (로컬) ──HTTP(로그인 쿠키)──▶ EasyERD 서버 (/api)

사전 준비

  • Claude Code 설치 (CLI 또는 IDE 확장)
  • Node.js 18 이상
  • 이 저장소(harness-test)를 로컬에 클론 — MCP 서버 소스가 erd-service/mcp/에 있습니다
  • EasyERD 서버 주소. 이 가이드는 배포 서버 http://toughdev.cafe24.com:8080 기준입니다(로컬 테스트는 http://localhost:8080)

1의존성 설치

클론한 저장소에서 MCP 패키지의 의존성을 설치합니다.

cd erd-service/mcp
npm install

2서비스 계정 만들기

MCP는 EasyERD에 로그인 계정으로 접속합니다. 본인 전용 계정을 하나 만드세요(아이디 3자 이상, 비밀번호 8자 이상). 그 계정으로 만든 다이어그램만 MCP에서 보이고 편집됩니다.

curl -X POST http://toughdev.cafe24.com:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"내아이디-mcp","password":"내비밀번호"}'
웹 화면 우측 상단 아바타 → 회원가입으로 만들어도 됩니다. 사람이 쓰는 계정과 분리하면(예: 홍길동-mcp) 관리가 편합니다.

3.mcp.json 작성

저장소의 프로젝트 루트에 .mcp.json 파일을 만들고 아래 내용을 넣습니다. 값(계정·비밀번호)은 본인 것으로 바꾸세요.

{
  "mcpServers": {
    "erd": {
      "command": "npx",
      "args": ["-y", "tsx", "erd-service/mcp/src/index.ts"],
      "env": {
        "ERD_BASE_URL": "http://toughdev.cafe24.com:8080",
        "ERD_USERNAME": "내아이디-mcp",
        "ERD_PASSWORD": "내비밀번호"
      }
    }
  }
}

CLI로도 등록할 수 있습니다.

claude mcp add erd \
  --env ERD_BASE_URL=http://toughdev.cafe24.com:8080 \
  --env ERD_USERNAME=내아이디-mcp \
  --env ERD_PASSWORD=내비밀번호 \
  -- npx -y tsx erd-service/mcp/src/index.ts
⚠️ .mcp.json에는 비밀번호가 평문으로 들어갑니다. 커밋·공유하지 마세요. .gitignore에 .mcp.json을 추가하는 것을 권장합니다. 특정 다이어그램을 시작 시 자동 선택하려면 env에 "ERD_DIAGRAM_ID": "5"처럼 id를 넣을 수 있습니다.

4재시작 & 연결 확인

MCP 서버는 시작 시점에 로드되므로 Claude Code를 재시작합니다. 그다음:

  • /mcp 입력 → erd 서버와 도구 목록이 보이면 연결 성공
  • 또는 "ERD 다이어그램 목록 보여줘"라고 요청 → list_diagrams 실행
첫 실행은 npx -y tsx가 tsx를 받아오느라 몇 초 걸릴 수 있습니다(최초 1회).

사용법

연결되면 자연어로 요청하면 됩니다. 예:

  • "주문 시스템 ERD 새로 만들어줘"
  • "User(사용자)와 Order(주문) 엔티티 추가하고, User→Order 1:M 비식별 관계 연결해줘"
  • "User에 email(이메일) varchar(255) 컬럼 추가해줘"
  • "방금 만든 다이어그램 요약 보여줘"

관계를 연결하면 상위 엔티티의 PK가 하위에 FK 컬럼으로 자동 생성됩니다(식별 관계면 FK가 하위 PK에도 포함).

도구 목록

참조 인자(엔티티·컬럼·source·target)는 id 또는 이름 둘 다 사용할 수 있습니다.

도구설명
list_diagrams내 다이어그램 목록
create_diagram빈 다이어그램 생성 + 현재 선택
select_diagram작업 대상 선택 (id 또는 이름)
get_diagram현재/지정 다이어그램 요약 조회
rename_diagram / delete_diagram이름 변경 / 삭제
add_entity엔티티 추가 (기본 id PK 포함)
update_entity / delete_entity수정 / 삭제 (연쇄 FK·관계 정리)
add_column / update_column / delete_column컬럼 CRUD
add_relationship관계 추가 + 상위 PK를 하위 FK로 자동 생성
update_relationship_type관계 타입 변경 (식별↔비식별)
delete_relationship관계 삭제 + 자동 FK 제거

문제 해결

증상원인 / 해결
도구가 안 보임.mcp.json이 프로젝트 루트에 있는지, Claude Code를 재시작했는지 확인. /mcp로 상태 확인
로그인 실패 (401)ERD_USERNAME/ERD_PASSWORD 확인, 서버에 그 계정이 가입돼 있는지 확인
token 쿠키 없음HTTPS 서버라면 ERD_BASE_URL이 https://인지 확인
모듈/tsx 못 찾음cd erd-service/mcp && npm install 실행 여부 확인
편집했는데 화면에 안 보임설계상 정상 — 다이어그램을 다시 열거나 새로고침(아래 주의사항)

주의사항

  • 새로고침 필요: MCP 편집은 DB에 저장됩니다. 이미 열려 있는 브라우저에는 자동 반영되지 않으니 다이어그램을 다시 열거나 새로고침하세요.
  • 마지막 저장 우선: 같은 다이어그램을 MCP와 브라우저에서 동시에 저장하면 나중 저장이 앞 저장을 덮어씁니다.
  • 계정 격리: 각자 자기 MCP 계정의 다이어그램만 보고 편집합니다. 공유하려면 같은 계정을 함께 쓰면 됩니다.
  • 서브타입(SubSet)·일괄 생성·실시간 동기화는 현재 범위 밖입니다.
