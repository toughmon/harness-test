# YourERD 사용자 매뉴얼

YourERD는 브라우저에서 ERD(Entity-Relationship Diagram, 개체-관계 다이어그램)를
시각적으로 작성하고, MySQL DDL·PNG로 내보내며, 로그인 시 다이어그램을 클라우드에
저장할 수 있는 온라인 ERD 작성 서비스입니다.

> 이 매뉴얼은 별도 설치 없이 웹 브라우저만으로 사용하는 일반 사용자를 위한 안내입니다.

---

## 1. 화면 구성

화면은 크게 3개 영역으로 나뉩니다. 엔티티·관계선·메모의 상세 편집은 화면 한쪽에
상시 고정된 패널이 아니라, 필요할 때 여는 **편집 모달**로 이루어집니다(→ 4.2·6.3·8.2).

```
┌─────────────────────────────────────────────────────────────┐
│  ① 상단 바 (YourERD · 실행취소/다시실행 · 저장 · 계정)            │
├──────────┬──────────────────────────────────────────────────┤
│          │                                                  │
│ ② 좌측    │              ③ 캔버스 (풀폭)                       │
│  사이드바  │       (엔티티·관계선 배치 + 편집 모달 트리거)          │
│          │                                                  │
│          │        ┌──────────────┐ ◀ 줌 툴바                │
└──────────┴──────────────────────────────────────────────────┘
```

| 영역 | 이름 | 역할 |
|------|------|------|
| ① | 상단 바 (Top Nav) | 브랜드, 실행취소/다시실행, 저장/불러오기, 계정 |
| ② | 좌측 사이드바 | 엔티티 추가, 내 다이어그램 목록, 엔티티 목록 |
| ③ | 캔버스 | 엔티티 배치·관계선 연결·줌/이동. 화면을 넓게 쓸 수 있도록 풀폭입니다 |

> **선택과 편집은 분리되어 있습니다.** 엔티티·관계선·메모를 **클릭하면 선택(하이라이트)**
> 만 되고, 실제 속성을 고치려면 **info(ⓘ) 아이콘 / ✎ 아이콘 / 우클릭 → 편집**으로
> 별도의 **편집 모달**을 열어야 합니다. 선택 상태는 모달을 닫아도 유지되며, `Delete`
> 키로 삭제할 때도 이 선택 상태를 기준으로 동작합니다.

## 3. 좌측 사이드바

- **Add Entity** — 캔버스에 새 엔티티(테이블)를 추가합니다.
- **Add Memo** — 캔버스에 스티키 노트(메모)를 추가합니다. 캔버스 빈 영역을 **더블클릭**해도 메모가 생성됩니다.
- **내 다이어그램** *(로그인 시에만 표시)* — 내 계정에 저장된 다이어그램 목록.
  - 항목 클릭 → 해당 다이어그램으로 전환
  - `＋` → 빈 캔버스로 새 다이어그램 시작
  - 항목에 마우스를 올리면 **이름 변경(✎)**, **복제(⧉)**, **삭제(🗑)** 아이콘이 나타납니다.
  - **복제** — 클릭하면 복제본 이름을 입력하는 창이 뜨고(기본값 "원본 이름 사본"), 확인하면
    현재 편집 중인 캔버스는 그대로 둔 채 원본과 동일한 내용의 새 다이어그램이 목록에 추가됩니다.
- **Entity List** — 현재 다이어그램의 엔티티 목록. 클릭하면 캔버스에서 해당
  엔티티가 선택(하이라이트)됩니다. 엔티티 색상과 논리명(한글)이 함께 표시됩니다.
- **접기/펼치기** — 헤더 오른쪽의 패널 접기 버튼(⊟)을 누르면 사이드바가 얇은 막대로
  접혀 캔버스를 넓게 볼 수 있습니다. 접힌 상태에서도 펼치기 버튼과 Add Entity
  단축 아이콘은 남아 있습니다.
- **하단 메뉴**
  - **MCP 연결** — 로그인 후 **개인 액세스 토큰(PAT)**을 발급하고, 토큰이 박힌 `claude mcp add --transport http …` 한 줄을 복사하는 모달. 이 한 줄을 Claude Code에 붙여넣으면 레포 복제·Node 설치·재시작 없이 바로 연결됩니다. 발급한 토큰은 목록에서 취소할 수 있습니다.
  - **MCP 연결 가이드** — 연결 방법 상세 설명 (`/mcp-guide.html`, 새 탭).
  - **Claude 프롬프트 가이드** — MCP로 ERD를 그릴 때 쓰는 프롬프트 예시 (`/prompt-guide.html`, 새 탭).
  - **Docs** — 이 매뉴얼 (`/manual.html`, 새 탭).
  - 세 가이드 페이지는 화면 언어를 영어로 두면 영문판(`/en/...`)으로 열립니다.

## 4. 엔티티(테이블) 작성

### 4.1 엔티티 추가
좌측 **Add Entity** 버튼을 누르면 캔버스에 새 엔티티가 생깁니다.

### 4.2 엔티티 선택·미리보기·편집
엔티티 헤더에는 **ⓘ (info) 아이콘**이 있습니다.

- **클릭** — 엔티티 본문(물리명, 논리명, 설명, 색상, 컬럼, SubSet)을 편집하는 **모달**을 엽니다.
- **마우스 올리기(호버)** — 클릭 없이 훑어볼 수 있는 **읽기전용 미리보기**가 뜹니다. 설명(Description)과
  UNIQUE 여부처럼 노드 본문에는 표시되지 않는 정보까지 한 번에 보여줍니다.
- **노드 더블클릭 빠른 편집** — 캔버스 상의 엔티티 **물리명·논리명(한글명)**이나 컬럼 **속성명·한글명·데이터 타입**을 **더블클릭**하면 모달을 열지 않고 바로 수정할 수 있습니다(→ 5.1).
- 엔티티 본문(헤더 제외)을 클릭하면 **선택(하이라이트)** 만 되며, 모달은 열리지 않습니다.
  또는 **우클릭 → 편집**으로도 같은 모달을 열 수 있습니다(→ 4.6).

모달에서 편집 가능한 항목:

| 항목                      | 설명 |
|-------------------------|------|
| **Table Name (물리명)**    | 실제 테이블명(영문). 예: `user`, `order` |
| **Logical Name (논리명)**  | 한글 명칭. 예: `사용자`, `주문` |
| **Description / Notes** | 테이블 설명·메모 |
| **Entity Color**        | 엔티티 헤더 색상(12색). 미니맵 색상도 함께 바뀝니다 |

> 노드와 사이드바, 편집 모달 모두 **물리명 + 논리명**을 함께 표시합니다.

### 4.3 엔티티 삭제
편집 모달 헤더의 **🗑(삭제)** 버튼을 누르거나, 엔티티를 **우클릭 → 삭제**하거나,
엔티티를 선택한 상태에서 **`Delete`** 키를 누르면 확인 후 삭제됩니다.
연결된 관계선과, 다른 엔티티에 자동 생성됐던 FK 컬럼도 함께 정리됩니다.

### 4.5 엔티티 접기 / 펼치기

엔티티 헤더 우측의 **접기 아이콘**을 누르면 컬럼 목록과 SubSet 영역이 감춰지고 **헤더만 남습니다.**
작은 노트북처럼 세로 공간이 부족할 때, 지금 보는 테이블 2~3개만 펼쳐 두고 나머지는 접으면
전체 구조와 상세를 한 화면에서 함께 볼 수 있습니다.

- 접힌 엔티티에는 **컬럼 수 배지**가 표시되어 규모를 알 수 있습니다.
- 접혀 있어도 **관계선 연결·선택·삭제·ⓘ 편집 모달**은 그대로 동작합니다.
- 줌 툴바의 **모두 접기 / 모두 펼치기** 버튼으로 한 번에 전환할 수 있습니다.
  모두 접은 뒤 **자동 정렬(🌳)** 을 누르면 간격까지 다시 계산되어 훨씬 촘촘해집니다.
- 접힘 상태는 **보기 설정**이라 다이어그램에 저장되지 않습니다. 다시 열면 모두 펼쳐진 상태로 시작합니다.

### 4.6 우클릭 컨텍스트 메뉴
엔티티(또는 관계선·메모)를 **우클릭**하면 **편집 · 삭제** 두 항목의 메뉴가 뜹니다.
info 아이콘·✎ 아이콘 클릭과 동일하게 편집 모달을 열 수 있는 대체 경로이며,
메모처럼 전용 아이콘이 없는 요소는 이 방법이 편집 모달을 여는 유일한 경로입니다.

## 5. 컬럼(속성) 관리

컬럼 및 엔티티 정보 관리는 **캔버스 노드 더블클릭 빠른 편집**과 **상세 모달 편집** 2가지 방식을 모두 지원합니다.

### 5.1 캔버스 노드 더블클릭 빠른 편집
상세 모달(ⓘ 아이콘)을 열지 않고도 캔버스 상의 엔티티 노드 텍스트를 **더블클릭**하여 즉시 수정할 수 있습니다.

- **속성명(물리명)**: 컬럼명을 더블클릭 후 수정 → `Enter` (예: `coupon_id`)
- **한글명(논리명)**: 한글명 텍스트를 더블클릭 후 수정. (한글명이 없을 때는 호버 시 나타나는 `+한글명` 힌트를 더블클릭하여 새로 입력 가능)
- **데이터 타입 및 크기**: 데이터 타입을 더블클릭 후 수정 → `Enter` (예: `VARCHAR(200)`, `DECIMAL(12,2)` 등으로 입력하면 타입명과 크기가 정규식으로 자동 분리 파싱되어 반영됩니다)
- **엔티티 이름/서브타입**: 엔티티 헤더의 영문 물리명과 한글 논리명, 서브타입 박스의 속성 정보도 동일하게 더블클릭으로 즉시 변경 가능합니다.

### 5.2 상세 모달 편집
엔티티 편집 모달의 **Columns** 영역에서 상세 속성(PK/FK, NOT NULL, UNIQUE, 순서 등)을 통합 관리합니다(엔티티의 ⓘ 아이콘 클릭으로 모달을 엽니다).

- **Add** — 새 컬럼 추가
- 컬럼 행을 클릭하면 펼쳐지며 상세 편집이 가능합니다.

| 편집 항목 | 설명 |
|-----------|------|
| 🔑 (PK) | 기본키 지정/해제 — PK 컬럼은 엔티티 상단에 모여 표시됩니다 |
| 🔗 (FK) | 외래키 지정/해제 |
| 물리명 | 컬럼명(영문). 예: `user_id` |
| 논리명 | 한글 명칭. 예: `사용자아이디` |
| 데이터 타입 | 아래 [지원 타입](#56-지원-데이터-타입) 중 선택 |
| size | 길이/자릿수. 예: VARCHAR `255` |
| NOT NULL | 필수 입력 여부 (노드에서 `*`로 표시) |
| UNIQUE | 유일값 제약 |

### 5.5 컬럼 순서 변경
컬럼 행 왼쪽의 **드래그 핸들(⠿)** 을 잡고 위아래로 끌어 순서를 바꿀 수 있습니다.
(순서 변경도 실행 취소가 가능합니다.)

### 5.6 지원 데이터 타입
`VARCHAR`, `INT`, `BIGINT`, `BOOLEAN`, `TEXT`, `DATE`, `DATETIME`, `TIMESTAMP`,
`DECIMAL`, `FLOAT`, `CHAR`, `SMALLINT`, `TINYINT`, `UUID`, `JSON`, `BLOB`

## 6. 관계(Relationship) 연결

### 6.1 관계선 만들기
1. 엔티티 위에 마우스를 올리면 상·하·좌·우에 **연결 핸들**이 나타납니다.
2. **부모(상위) 엔티티의 핸들**에서 **자식(하위) 엔티티**로 드래그합니다.
3. 관계 종류 선택 창이 열리면 원하는 타입을 고릅니다.

> 드래그를 시작한 쪽이 항상 **부모(1쪽)** 로 설정됩니다.

### 6.2 관계 종류
관계를 만들 때 선택 창에서 6가지 프리셋을 빠르게 고를 수 있고(각 타입 옆에 선 모양
미리보기 표시), 만든 뒤에는 편집 모달에서 좌/우 절반을 더 세밀하게 조정할 수 있습니다(→ 6.3).

| 라벨 | 카디날리티 | 선 스타일 | FK 생성 규칙 |
|------|-----------|----------|--------------|
| 1:M 식별자 상속 (점선 + 실선) | 1:다 | 부모 점선 + 자식 실선 | FK가 **자식 PK에 포함** + NOT NULL |
| 1:M 식별자 상속 (실선 + 실선) | 1:다 | 전체 실선 | FK가 **자식 PK에 포함** + NOT NULL |
| 1:M 비식별 (점선 + 실선) | 1:다 | 부모 점선 + 자식 실선 | FK가 PK 미포함 + NOT NULL |
| 1:M 비식별 (점선 + 점선) | 1:다 | 전체 점선 | FK가 PK 미포함 + **NULL 허용** |
| 1:1 식별자 상속 (점선 + 실선) | 1:1 | 부모 점선 + 자식 실선 | FK가 **자식 PK에 포함** + NOT NULL |
| 1:1 비식별 (점선 + 실선) | 1:1 | 부모 점선 + 자식 실선 | FK가 PK 미포함 + NOT NULL |

> 1:1의 "실선+실선"·"점선+점선"은 의미가 모호해 선택 목록에서 제외했습니다(필요하면 6.3 좌/우 절반 편집으로 표현 가능).

**표기법 (바커 표기법 기반)**
- **까마귀발(crow's foot)** — 1:다 관계의 "다(M)" 쪽 표시
- **점선(부모쪽)** — 선택적(optional) 참여, **실선(자식쪽)** — 필수(mandatory) 참여
- **식별자 막대(uid bar)** — 식별 관계에서 자식 쪽에 추가되는 짧은 세로선

**FK 자동 생성** — 관계를 만들면 부모의 PK를 참조하는 FK 컬럼이 자식 엔티티에
자동으로 추가됩니다(컬럼명·논리명은 상위 PK명을 그대로 사용). 관계를 삭제하면
자동 생성된 FK도 정리됩니다.

### 6.3 관계 편집 (좌/우 절반 설정)·삭제
관계선을 클릭하면 **선택(하이라이트)** 되고, 선 중간에 작은 **✎ 편집 아이콘**이 나타납니다.
이 아이콘을 클릭하면(또는 관계선을 **우클릭 → 편집**) *관계 속성* 편집 **모달**이 열립니다.
선에서 **부모 쪽 절반·자식 쪽 절반**(각 엔티티에 가까운 절반, 화면 위치와 무관)을 독립적으로
설정해 모든 관계를 표현할 수 있습니다. 모달에는 각 절반이 어느 엔티티 쪽인지 이름으로 표시됩니다.
- **부모 쪽 / 자식 쪽 참여** — 각 절반을 **실선(필수)** 또는 **점선(선택)**으로.
  두 절반의 조합으로 실선+실선·점선+점선·실선+점선·점선+실선이 모두 가능합니다.
- **카디널리티** — 자식 쪽을 **1(단일)** 또는 **다(까마귀발)**로 전환합니다.
- **식별 관계** — 켜면 자식 FK가 PK에 포함되고 식별 막대가 표시됩니다.
  *자식 쪽이 점선(선택)이면 식별 FK가 NULL을 허용할 수 없어 식별 관계로 지정할 수 없습니다(체크 자동 해제·비활성).*
- **관계 삭제** — 모달 하단의 **관계 삭제** 버튼을 누르거나, 관계선을 **우클릭 → 삭제**하거나,
  관계선을 선택한 상태에서 **`Delete`** 키를 눌러 제거합니다(자동 생성 FK도 함께 정리).

변경은 즉시 반영되며 `Ctrl+Z`로 되돌릴 수 있습니다. 모달 상단에 현재 설정의 선 모양
미리보기가 표시됩니다.

### 6.4 관계선 모양 조정 — 끝점 위치·우회 경로

**끝점 위치 옮기기**
관계선은 기본적으로 두 엔티티의 위치에 맞춰 연결 위치가 자동으로 정해집니다. 원하는
위치에 붙이고 싶다면 관계선을 클릭해 선택한 뒤, 양 끝에 나타나는 **둥근 핸들**을 드래그하세요.
- 끝점은 **연결된 같은 엔티티**의 테두리 위에서만 움직입니다(다른 엔티티로 옮겨지지 않음).
  가장 가까운 면(상·하·좌·우)에 자동으로 달라붙습니다.
- 엔티티를 이동하거나 컬럼을 추가해 크기가 바뀌어도 옮긴 위치가 **상대적으로 유지**됩니다.
- 핸들을 **더블클릭**하면 자동 위치로 되돌아갑니다.
- 옮긴 위치는 저장되며 `Ctrl+Z`로 되돌릴 수 있습니다. *(자기 참조 관계는 끝점 드래그 미지원)*

**선을 우회시키기 — 사이에 놓인 엔티티 피하기**
A와 B를 잇는 관계선 위에 C 엔티티가 겹쳐 선이 가려질 때, **관계선을 위/아래로 드래그**하면
양쪽 엔티티에서 나온 선이 늘어나면서 드래그한 높이로 돌아가는 직각 경로가 만들어집니다.
- **잡은 구간만 움직입니다.** 우회한 선은 세 구간으로 나뉘고, 각각 자기 방향으로만 끌립니다
  (좌우 배치 기준 — 위아래 배치면 역할이 서로 바뀝니다):
  | 잡는 곳 | 드래그 방향 | 효과 |
  |---|---|---|
  | 가운데 **우회선**(가로로 도는 구간) | 위/아래 | 우회선 높이 |
  | **부모 쪽 다리**(내려가는 세로 구간) | 좌/우 | 부모 쪽만 이동 |
  | **자식 쪽 다리**(올라가는 세로 구간) | 좌/우 | 자식 쪽만 이동 |
- 한쪽 다리를 옮겨도 **반대쪽 다리는 그대로**입니다. 두 다리를 각각 조절해 장애물을
  **앞에서 내려갈지 지나쳐서 내려갈지** 양쪽 따로 정할 수 있습니다.
- 선 위에 마우스를 올리면 커서(↕ / ↔)가 그 구간을 어느 방향으로 끌 수 있는지 알려줍니다.
  아직 우회하지 않은 직선은 전체가 우회선이라 위/아래로 끌면 꺾입니다.
- 축은 끝점이 어느 면(상·하·좌·우)에 붙어 있는지가 아니라 **두 엔티티의 배치**로 판단하므로,
  끝점을 하단 면에 붙여 놓은 좌우 배치에서도 위/아래로 드래그하면 됩니다.
- 선 위 아무 곳에서나 드래그할 수 있고, 선택 시 선 가운데 나타나는 **✎ 아이콘에서 끌어도**
  됩니다. 움직이지 않고 그냥 클릭하면 지금처럼 편집 모달이 열립니다.
- 우회 정도는 자동 중간점 기준 **상대값**으로 저장되어, 엔티티를 옮기면 우회 모양도 함께 따라갑니다.
- **선을 더블클릭**하거나 관계 편집 모달의 **우회 해제(자동 경로로 복귀)** 버튼을 누르면
  자동 경로로 돌아갑니다. `Ctrl+Z`로도 되돌릴 수 있습니다. *(자기 참조 관계는 우회 미지원)*

### 6.5 관계를 특정 서브타입 전용으로 지정하기
부모 또는 자식 엔티티에 [서브타입](#7-배타적-서브타입-subset)이 있으면, 그 서브타입에만
해당하는 관계를 두 가지 방법으로 만들 수 있습니다.

**방법 A — 서브타입 박스에서 바로 드래그 (권장)**
서브타입 박스 오른쪽에 작은 연결점이 있습니다. 여기서 다른 엔티티(또는 다른 서브타입)로
바로 드래그하면, 관계 종류를 고르는 즉시 그 서브타입 스코프가 자동으로 지정됩니다 —
패널을 따로 열어 조정할 필요가 없습니다.

**방법 B — 만든 뒤 패널에서 지정**
관계 편집 패널의 해당 절반 아래에 **구체적 대상** 드롭다운이 나타납니다. 여기서
서브타입을 고르면 이 관계가 그 서브타입에만 해당함을 표시할 수 있습니다(방법 A로 만든
관계도 이 드롭다운으로 스코프를 나중에 바꾸거나 확인할 수 있습니다).

- **자식 쪽을 서브타입으로 지정**하면 자동 생성 FK 컬럼이 엔티티 전체가 아니라 그
  서브타입 박스 안으로 이동합니다 — SQL 내보내기에서도 그 서브타입일 때만 값이 채워질
  수 있는 nullable 컬럼으로 롤업되고, 배타성 CHECK 제약에 자동으로 포함됩니다.
  이 경우 **식별 관계로 지정할 수 없습니다**(서브타입 컬럼은 조건부라 PK가 될 수 없음 —
  체크 자동 해제·비활성).
- **부모 쪽을 서브타입으로 지정**하면 패널·FK 생성에는 영향이 없고, 라벨에
  "엔티티명 · 서브타입명"으로 표시되어 어떤 의도의 관계인지 기록해 둘 수 있습니다.
- 드롭다운에서 **(엔티티 전체)**를 선택하면 스코프가 해제되어 원래대로 돌아갑니다.
- 자식 쪽 스코프로 지정된 서브타입을 삭제하면 그 관계(및 FK)도 함께 정리됩니다.
  부모 쪽 스코프로만 지정된 서브타입을 삭제하면 관계는 유지되고 스코프만 해제됩니다.

## 7. 배타적 서브타입 (SubSet)

하나의 슈퍼타입 안에 배타적인 하위 엔티티 그룹을 표현할 때 사용합니다
(예: `결제` 안에 `카드결제` / `계좌이체`).

엔티티 편집 모달 하단 **SubSet (서브타입)** 영역에서 관리합니다.

- **Add Subtype** — 서브타입 추가
- **SubSet 이름** — 그룹(구분자) 이름
- **배타 (Exclusive)** — 체크 시 하위 타입이 서로 겹치지 않음
- **완전 (Complete)** — 체크 시 반드시 하위 타입 중 하나에 속함
- 각 서브타입 카드에서 **물리명·논리명**과 **고유 속성(컬럼)** 을 관리합니다.

> 서브타입은 PK를 슈퍼타입과 공유하므로 자체 PK 없이 **고유 속성**만 가집니다.
> SQL 내보내기 시 **단일 테이블**로 롤업되며, 구분자 컬럼·CHECK 제약이 자동 생성됩니다.

## 8. 메모 (스티키 노트)

설계 의도·주의사항·TODO 등 자유로운 텍스트를 캔버스 위 어디든 배치할 수 있습니다.

### 8.1 메모 추가
- 좌측 사이드바의 **Add Memo** 버튼 클릭
- 또는 캔버스 빈 영역을 **더블클릭**

메모를 추가하면 자동으로 선택 상태가 됩니다(모달이 자동으로 열리지는 않습니다 — 아래 8.2 참고).

### 8.2 메모 편집
- **노드 내 textarea** — 메모 위에서 **직접 클릭해 바로 텍스트를 입력**할 수 있습니다. 별도로
  모달을 열지 않아도 되는 가장 빠른 방법입니다.
- **편집 모달** — 메모는 전용 아이콘이 없으므로, 메모를 **우클릭 → 편집**으로 모달을 엽니다.
  텍스트를 더 넓은 영역에서 편집하고, 6가지 배경 색상(노란·초록·파란·빨간·보라·주황) 중
  하나를 선택할 수 있습니다.

### 8.3 메모 크기 조절
메모 테두리의 **리사이즈 핸들**을 드래그해 자유롭게 크기를 바꿀 수 있습니다
(메모를 클릭하면 핸들이 표시됩니다).

### 8.4 메모 이동
메모를 **드래그**해 캔버스 위 원하는 위치로 옮길 수 있습니다.

### 8.5 메모 삭제
- 메모 우상단의 **× 버튼** (마우스를 올리면 표시) — 확인 없이 즉시 삭제
- 메모를 **우클릭 → 삭제** (확인 후 삭제)
- 편집 모달을 연 뒤 하단의 **삭제** 버튼 (확인 후 삭제)
- 메모를 선택한 상태에서 **`Delete`** 키 (확인 후 삭제)

삭제·크기·위치 변경 모두 `Ctrl+Z`로 되돌릴 수 있습니다.

> 메모는 JSON 저장/불러오기 파일에 포함됩니다. 로그인 시 DB 저장에도 포함됩니다.

## 9. 캔버스 조작 (하단 줌 툴바)

캔버스 하단 가운데의 플로팅 툴바에서 사용합니다.

| 버튼 | 아이콘 | 기능 |
|------|--------|------|
| 축소 | 🔍− | 줌 아웃 |
| 배율 표시 | `102%` | 현재 확대 배율 |
| 확대 | 🔍＋ | 줌 인 |
| 화면 맞춤 | ⛶(fit) | 모든 엔티티가 보이도록 맞춤 |
| 모두 접기 / 모두 펼치기 | ⌃⌄ | 모든 엔티티를 헤더만 남기고 접거나 다시 펼침 (→ 4.5) |
| 자동 정렬 | 🌳 | 관계 구조에 맞춰 엔티티 자동 배치 (실행 취소 가능) |
| PNG 내보내기 | 📷 | 다이어그램을 PNG 이미지로 저장 |
| SQL 내보내기 | 🗄 | MySQL DDL(`.sql`)로 내보내기 |
| 전체화면 | ⛶ | 캔버스를 브라우저 전체화면으로 확장 |

### 9.1 전체화면 모드
전체화면 버튼을 누르면 상단 바·사이드바가 사라지고 **캔버스가 화면 전체**를
채웁니다. 전체화면 상태에서도 줌 툴바와 미니맵, 편집 모달은 그대로 사용할 수 있습니다.
**`Esc`** 키 또는 전체화면 종료 버튼으로 빠져나옵니다.

### 9.2 미니맵
캔버스 우측 하단의 미니맵으로 전체 구조를 한눈에 보고 빠르게 이동할 수 있습니다.
미니맵의 각 블록 색상은 엔티티 색상과 동일합니다.

### 9.3 화면 이동·확대
- **이동(팬)** — 빈 캔버스를 드래그
- **확대/축소** — 마우스 휠 또는 줌 툴바
- **엔티티 이동** — 엔티티를 드래그

### 9.4 여러 개 한 번에 선택·이동하기 (다중 선택)
빈 캔버스에서 **`Shift` 키를 누른 채 드래그**하면 사각형 선택 박스가 그려지고,
그 안에 완전히 들어온 엔티티·메모가 모두 선택됩니다.

- 선택된 항목 중 하나를 **드래그**하면 나머지도 상대 위치를 유지한 채 함께 이동합니다.
- 우측에 **"N개 선택됨"** 패널이 뜨며, 여기서 **선택 항목 삭제** 버튼이나 **`Delete`** 키로
  선택한 항목을 한 번에 삭제할 수 있습니다(연결된 관계선·자동 생성 FK 컬럼도 함께 정리).
- 그룹 이동·일괄 삭제 모두 `Ctrl+Z` **한 번**으로 전체가 복원됩니다.
- 선택을 풀려면 빈 캔버스를 클릭하세요.

> 관계선은 다중 선택 대상이 아닙니다(엔티티·메모만 그룹으로 묶입니다).

## 10. 저장 · 불러오기

### 10.1 JSON 파일로 저장/열기 (로그인 불필요)
- **Save** — 현재 다이어그램을 `.json` 파일로 내려받습니다.
- **불러오기(📂)** — 저장한 `.json` 파일을 다시 엽니다.

### 10.2 클라우드(DB) 저장 (로그인 필요)
1. 우측 상단 **계정(👤)** 버튼으로 아이디·비밀번호 가입/로그인을 합니다.
2. 상단 **DB 저장** 버튼으로 내 계정에 저장합니다.
3. 저장한 다이어그램은 좌측 **내 다이어그램** 목록에서 전환·이름변경·삭제할 수 있습니다.

> 다이어그램 이름 옆의 점(●)은 저장되지 않은 변경이 있다는 표시입니다.
> 다른 다이어그램으로 전환하거나 로그아웃할 때 미저장 변경이 있으면 경고합니다.

### 10.3 공유 및 실시간 함께 보기 (로그인 필요)
DB에 저장한 다이어그램을 **링크로 공유**해 여러 사람이 실시간으로 함께 볼 수 있습니다.

1. 공유할 다이어그램을 연 뒤, 상단 **공유** 버튼을 누릅니다. (DB에 저장된 다이어그램만 공유 가능)
2. **뷰어 링크 생성**을 누르면 `https://.../d/…` 형태의 링크가 만들어집니다. **복사(⧉)** 버튼으로 복사해 전달하세요.
3. 링크를 받은 사람이 **로그인**하면, 소유자가 편집하는 내용이 그 사람 화면에 **실시간으로 반영**됩니다.
4. 링크로 들어온 사람은 **읽기 전용**입니다(상단에 "읽기 전용" 배지). 편집 버튼·단축키는 비활성화되며, **나가기**로 내 작업으로 돌아갑니다.
5. 상단의 참여자 **아바타**로 지금 함께 보고 있는 사람을 확인할 수 있습니다.
6. 공유 모달의 목록에서 링크를 **폐기(🗑)**하면 그 링크로는 더 이상 접속할 수 없습니다.

> 링크 토큰은 발급 시 한 번만 표시되며 서버에는 해시만 저장됩니다. 링크는 **그 다이어그램 하나**만 열 수 있고, 소유자의 다른 다이어그램이나 계정에는 접근할 수 없습니다.
> 여러 사람이 **동시에 편집**하는 기능은 다음 단계에서 제공될 예정입니다(현재는 소유자가 편집, 나머지는 함께 보기).

## 11. 내보내기

| 형식 | 방법 | 내용 |
|------|------|------|
| **PNG** | 줌 툴바 📷 | 현재 다이어그램을 이미지로 저장 |
| **SQL (MySQL)** | 줌 툴바 🗄 | 엔티티/컬럼/FK를 MySQL 8.x `CREATE TABLE` DDL로 변환. 논리명·설명은 COMMENT로, PK/UNIQUE/NOT NULL 제약과 복합 FK 제약 포함, 부모 우선 정렬 |
| **JSON** | 상단 Save | 작업 파일 형식(다시 불러오기용) |

> YourERD가 스스로 만드는 주석(파일 헤더, 서브타입 구분자 COMMENT)은 내보낼 때의 화면 언어를
> 따릅니다. 직접 입력한 논리명·설명은 번역되지 않고 그대로 나갑니다.

## 13. 빠른 시작 (튜토리얼)

1. **Add Entity** 로 엔티티를 추가합니다.
2. 엔티티의 **ⓘ 아이콘**을 클릭해 편집 모달을 열고 **물리명/논리명**을 입력합니다. (예: `user` / `사용자`)
3. **Columns → Add** 로 컬럼을 추가하고, 첫 컬럼은 🔑(PK)로 지정합니다.
4. 엔티티를 하나 더 만든 뒤, 부모 엔티티의 **연결 핸들**을 자식 엔티티로 드래그해
   관계를 만듭니다. → FK가 자동으로 생성됩니다.
5. 줌 툴바의 **자동 정렬(🌳)** 로 보기 좋게 배치합니다.
6. **SQL 내보내기(🗄)** 로 DDL을 받거나, **Save** 로 작업 파일을 보관합니다.
7. (선택) 로그인 후 **DB 저장** 으로 클라우드에 보관합니다.

## 14. 자주 묻는 질문

**Q. 로그인하지 않아도 쓸 수 있나요?**
네. 엔티티/관계 편집, PNG·SQL 내보내기, JSON 파일 저장/불러오기는 로그인 없이
사용할 수 있습니다. **클라우드(DB) 저장**만 로그인이 필요합니다.

**Q. 관계 타입을 잘못 골랐어요.**
관계선을 선택한 뒤 ✎ 아이콘(또는 우클릭 → 편집)으로 **관계 속성** 모달을 열면 좌/우 절반
(실선·점선), 카디널리티(1·다), 식별 여부를 언제든 바꿀 수 있습니다. 식별↔비식별 전환 시
FK 제약(PK 포함 여부·NULL 허용)이 자동으로 조정됩니다.

**Q. 부모 엔티티를 지웠더니 자식의 FK 컬럼은요?**
참조가 사라진 자동 생성 FK 컬럼은 함께 정리됩니다. (실행 취소로 복원 가능)

**Q. 작업 내용이 자동 저장되나요?**
아니요. 명시적으로 **Save(JSON)** 또는 **DB 저장**을 눌러야 보관됩니다.
이름 옆 점(●) 표시로 미저장 여부를 확인하세요.

**Q. 언어를 바꾸면 내 다이어그램도 바뀌나요?**
아니요. 언어 전환은 **화면 문구만** 바꿉니다. 직접 입력한 이름·논리명·설명은 사용자 데이터라
번역되거나 고쳐지지 않으며, 앱이 자동으로 넣는 기본값(`Entity1`, `id`, `column`, `SubType1`,
`SubSet` 등)도 언어와 무관하게 항상 동일합니다.

## 15. 화면 언어 (한국어 / English)

상단 바의 **🌐 언어 버튼**으로 화면 언어를 한국어(KO)와 영어(EN) 사이에서 전환합니다.

- 기본값은 **한국어**입니다. 브라우저 언어를 자동으로 감지하지 않고, 직접 고른 값만 사용합니다.
- 선택한 언어는 **이 브라우저에 저장**되어 새로고침·재방문 후에도 유지됩니다.
- 좌측 사이드바의 세 가이드 페이지(MCP 연결 가이드 · Claude 프롬프트 가이드 · Docs)도
  선택한 언어의 판본으로 열립니다. 가이드 페이지 안에서도 목차 하단의 **🌐** 링크로 서로 오갈 수 있습니다.

**언어를 바꿔도 달라지지 않는 것** — 다이어그램에 저장되는 값은 전부 그대로입니다.

| 구분 | 예 | 언어 전환 시 |
|------|-----|--------------|
| 내가 입력한 값 | 엔티티·컬럼의 물리명/논리명, 설명, 메모 내용, 다이어그램 이름 | 변경 없음 |
| 앱이 넣는 기본값 | `Entity1`, `id`, `column`, `SubType1`, `SubSet`, 자기참조 FK의 `parent_` 접두사 | 변경 없음(항상 영문) |
| 새로 만들 때의 입력창 기본 문구 | 저장 시 "새 다이어그램", 복제 시 "○○ 사본" | 만드는 시점의 언어를 따름 |
| SQL 내보내기의 도구 생성 주석 | 파일 헤더, 서브타입 구분자 COMMENT | 내보내는 시점의 언어를 따름 |

> 이미 저장해 둔 다이어그램의 이름은 언어를 바꿔도 소급해서 바뀌지 않습니다.
